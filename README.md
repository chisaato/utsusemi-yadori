# Utsusemi-Yadori 蝉宿

一个功能超丰富的 Frida 管理模块,支持 Magisk/KSU/SukiSU/APatch/FolkPatch 并且具备以下功能.

- frida-server 的启动与停止
- frida-gadget 按应用注入

然后在此之上,增加二进制的更新,以及自定义二进制下载.

还有 WebUI 用来控制这一切.

参考项目

- [magisk-frida](https://github.com/virb3/magisk-frida)
- [ZygiskFrida](https://github.com/lico-n/ZygiskFrida)
